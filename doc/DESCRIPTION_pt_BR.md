O phpMyAdmin é uma ferramenta de software livre escrita em PHP, destinada à administração do MySQL via web. O phpMyAdmin suporta uma ampla gama de operações no MySQL e no MariaDB. Operações frequentemente utilizadas (gerenciamento de bancos de dados, tabelas, colunas, relações, índices, usuários, permissões, etc.) podem ser realizadas através da interface do usuário, mantendo-se a possibilidade de executar diretamente qualquer instrução SQL.
